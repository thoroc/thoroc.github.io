## Incident 2026-08-16 — aislop gate red on main after PR #3

- **Symptom:** `aislop` workflow failed on the push to main (whole-repo gate), passed on PR + locally.
- **Root cause:** whole-repo gate type-checks `src/`; `tsconfig.json` includes `.astro/types.d.ts`, which is
  gitignored and only generated by `astro sync`/`dev`/`build`. Fresh CI checkout has no `.astro/` → TS2307
  `astro:content` + `*.yaml?raw`. PR gate passed because changed-files scope excluded src; local passed because
  prior build generated types.
- **Reproduced locally:** `rm -rf .astro && aislop ci .` → 85/2 errors; `bun run astro sync` → 100/0.
- **Fix:** added `bun run astro sync` after `bun install` in `.github/workflows/aislop.yml` and
  `.github/workflows/ai-hygiene.yml` (ai-hygiene also runs the whole-repo check on main and would report a spurious
  aislop ⚠️).
- **Fix PR:** <https://github.com/thoroc/thoroc.github.io/pull/4> (branch `fix/aislop-astro-sync`, commit `fd832ac`).
- **Learning:** whole-repo aislop/typecheck gates need generated framework types before running; keep the gate's environment in sync with `astro sync`.
