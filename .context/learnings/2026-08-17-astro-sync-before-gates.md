# Generate framework types before whole-repo gates

## Learning

In CI, run `bun run astro sync` after `bun install` and before any whole-repo aislop/typecheck gate.

## Evidence

`.astro/types.d.ts` is gitignored and only generated by `astro sync`/dev/build. Fresh CI checkouts (and any local
checkout before the first build) fail with TS2307 (`astro:content`, `*.yaml?raw`). Reproduced locally:
`rm -rf .astro && aislop ci .` → 85/2 errors; `bun run astro sync` → 100/0. Fix committed as `fd832ac`
(PR #4, `fix/aislop-astro-sync`).

## Rule

- Whole-repo aislop/typecheck gates need generated framework types present before running.
- Add the framework type-generation step to the workflow right after dependency install, alongside `astro sync` in any advisory gate that scans the whole repo on `main`.
